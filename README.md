# AI Invoice Operations & Compliance Platform

AI-powered invoice processing, GST validation, compliance automation, financial risk analysis, and enterprise invoice operations.

---

# Features

- AI Invoice Data Extraction
- PDF / Image / DOCX Invoice Support
- GST & VAT Validation
- Fraud & Risk Detection
- Duplicate Invoice Detection
- AI Confidence Scoring
- Invoice Analytics Dashboard
- SQLite Database Storage
- CSV / JSON / Excel Export
- Enterprise Audit Ledger
- Vendor Spend Analytics
